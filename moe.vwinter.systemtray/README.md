# v-systemtray (`moe.vwinter.systemtray`)

A fork of Plasma's System Tray applet (`org.kde.plasma.systemtray`), ported
from plasma-workspace (branch `Plasma/6.7`). It is a compiled applet: the QML
is embedded in the plugin and relies on the C++ StatusNotifier host/model.

## Install

```sh
make install    # install the KPackage and build/install the plugin
make restart
```

From the monorepo root, `make install` installs every add-on.

## Build requirements

The plugin is compiled, so it needs these packages installed system-wide
(on Arch Linux: `sudo pacman -S cmake extra-cmake-modules`):

- cmake >= 3.16 and extra-cmake-modules
- Qt 6 (Core, Gui, GuiPrivate, Widgets, Quick, DBus)
- KF6 (Config, CoreAddons, IconThemes, I18n, KIO, JobWidgets, Service,
  ItemModels, WindowSystem, XmlGui), KF6StatusNotifierItem, libplasma,
  libplasmaquick

`make build` compiles without installing or restarting Plasma.

The plugin is installed to
`~/.local/lib/qt6/plugins/plasma/applets/moe.vwinter.systemtray.so`, and
plasmashell must be told to look there (see the appmenu README for the
`QT_PLUGIN_PATH` environment.d note). `make uninstall` removes both the
KPackage and the plugin.

## Layout

- `package/` — the KPackage (metadata, config, QML sources)
- `src/` — the C++ applet (StatusNotifier host/model, plasmoid registry),
  forked from plasma-workspace
- `vendor/libdbusmenuqt/` — the DBusMenu importer, vendored from
  plasma-workspace
- `vendor/dbus/` — the StatusNotifier DBus interface XML used to generate the
  proxies at build time
- `CMakeLists.txt` — the plugin build (driven by the Makefile)

## Notes

- `src/config-X11.h` is normally generated by plasma-workspace's build; here it
  is shipped directly (the applet only uses `HAVE_X11` to guard a runtime
  `KWindowSystem::isPlatformX11()` check).
- The running applet uses the QML compiled into the plugin, so rebuild the
  plugin after any QML change.
